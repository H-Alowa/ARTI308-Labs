# ARTI308 – Lab 3: Exploratory Data Analysis (EDA)

## Objective
Apply exploratory data analysis (EDA) techniques to a car price dataset in
order to understand its structure, missing values, distributions, and
relationships between variables.

## Dataset
- Car price dataset containing information such as brand, year, engine size,
mileage, fuel type, transmission, condition, and price.

## Notebook Contents
The notebook includes the following steps:
- Checking missing values
- Checking duplicate rows
- Number of rows and columns
- Data types of columns
- Descriptive summary statistics
- Univariate analysis
- Bivariate analysis (Mileage vs Price)
- Correlation matrix and interpretation

## Tools Used
- Python
- pandas
- matplotlib

- seaborn
