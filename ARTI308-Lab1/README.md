# ARTI308 Lab 1 – Getting Started with Git and GitHub

In this lab, I learned how to use GitHub for version control and project sharing.

First, I created a GitHub account and verified my email. Then I created my first repository and added a README file. I practiced editing files directly on GitHub and committing changes.

I also learned how to upload project files into a repository and understand the concepts of repositories, branches, commits, and pull requests.

Additionally, I installed Visual Studio Code and the required extensions and created my first Jupyter Notebook file.

This lab helped me understand the basics of Git and GitHub for managing and sharing projects.
