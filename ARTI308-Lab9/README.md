# 🌳 Decision Trees and Random Forest Project

## 📌 Overview

This project demonstrates the implementation and evaluation of **Decision Tree** and **Random Forest** models for classification tasks. The goal is to compare their performance and understand how ensemble methods improve accuracy.

## 🚀 Features

* Data preprocessing and cleaning
* Implementation of Decision Tree classifier
* Implementation of Random Forest classifier
* Model evaluation using accuracy and other metrics
* Visualization of results

## 🛠️ Technologies Used

* Python
* Jupyter Notebook
* NumPy
* Pandas
* Matplotlib / Seaborn
* Scikit-learn

## 📊 Workflow

1. Load and explore the dataset
2. Perform data preprocessing
3. Split data into training and testing sets
4. Train Decision Tree model
5. Train Random Forest model
6. Evaluate and compare results

## 📈 Results

Random Forest generally provides better performance due to its ensemble nature, reducing overfitting compared to a single Decision Tree.
