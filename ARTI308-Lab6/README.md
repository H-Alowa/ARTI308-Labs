# ARTI308 Lab 6 – Linear Regression

## Description
This lab explores the use of **Linear Regression** to predict annual customer spending based on user activity data from an ecommerce dataset.

## Objectives
- Analyze the dataset using EDA techniques  
- Visualize relationships between features  
- Build a Linear Regression model  
- Evaluate model performance  

## Dataset
Ecommerce Customers dataset (CSV file)

## Tools & Libraries
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn
