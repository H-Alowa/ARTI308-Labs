# ARTI308 Lab 2 – Car Price Prediction

## Dataset Description
This dataset contains information about cars including brand, year, engine size, fuel type, transmission, mileage, condition, model, and selling price. Some values are missing and require preprocessing.

## Machine Learning Task
This is a supervised learning regression problem.

## Target Variable
Price – the selling price of the car.

## Problem Statement
The goal is to predict the selling price of a car based on its features such as brand, year, engine size, mileage, fuel type, transmission, condition, and model.

## Challenges
The dataset contains missing values and categorical features which must be handled before training a machine learning model.
